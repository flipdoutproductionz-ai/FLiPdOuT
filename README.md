# FLiPdOuT ProDucTioNz

Premium website repository for the FLiPs Flight Ops Companion launch and future FLiPdOuT releases.

## Stack
- HTML
- CSS
- JavaScript
- GitHub Pages
- Stripe Checkout

## Folder Structure
- `index.html` — main landing page
- `assets/css/style.css` — site styles
- `assets/js/main.js` — site interactions
- `assets/img/` — gallery and hero images
- `assets/video/` — explainer video
- `assets/audio/` — podcast audio
- `.github/workflows/deploy.yml` — GitHub Pages deploy workflow
